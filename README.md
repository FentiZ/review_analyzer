# Review Analyzer

Консольна програма для аналізу тональності англомовних відгуків за допомогою двох готових моделей Hugging Face.

## Запуск на Windows (PowerShell)

Відкрийте PowerShell у папці проєкту та виконайте:

```powershell
python --version
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python main.py
```

Якщо PowerShell не дозволяє активувати віртуальне середовище, можна запустити програму без активації:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

При першому запуску відповідного пункту меню модель завантажується з інтернету. Після цього файли зазвичай використовуються з локального кешу. API-ключ не потрібен для цих публічних моделей.

## Меню

- `1` — аналіз одного власного відгуку;
- `2` — аналіз усіх 40 відгуків за допомогою RoBERTa;
- `3` — порівняння RoBERTa та DistilBERT на тих самих 40 відгуках;
- `4` — окреме дослідження короткого, довгого, саркастичного й суперечливого відгуків;
- `5` — введення кількох своїх відгуків;
- `0` — вихід.

## Результати

- `results.csv` — результати всіх виконаних аналізів. Нові запуски дописують рядки. Відкривається в Excel.
- `report.md` — звіт з реальними результатами для 40 відгуків, створюється після **пункту 3**.
- `edge_cases.md` — додатковий звіт зі складними прикладами, створюється після **пункту 4**.

У звіті містяться значення, фактично отримані після запуску моделей. Попередньо згенерованих або вигаданих прогнозів немає.

## Моделі

1. `cardiffnlp/twitter-roberta-base-sentiment-latest` (Positive / Neutral / Negative)
2. `distilbert/distilbert-base-uncased-finetuned-sst-2-english` (Positive / Negative)

Бінарна модель не має нейтрального класу. Оцінка confidence не гарантує правильність класифікації. Для інтерпретації неоднозначних відгуків потрібна перевірка людиною.
